These eleven cases were selected from the completed fifteen-question evaluation because their recorded responses passed source review. This is a curated demonstration set. The complete diagnostic run scored thirteen passes, one partial answer and one failure, as recorded in final-evaluation.md. Selection does not measure accuracy on new questions.

Use questions 1 and 2 in the same conversation, keeping the actual first answer. Start a new conversation for every remaining question. The recorded answers below come from the original run. No new provider calls were made for this selection.
